日期：2026-11-23。[实施计划](../superpowers/plans/2026-11-23-strengthening-12-evaluation.md)

## 评测口径

保留旧检索 20 题、旧 Agent 12 场景和原始报告。旧真实 Agent 全量报告为 11/12，唯一自动失败是身份场景的状态断言。新版判定发布后的真实调用仅定向跑过 2 场景、3 请求。这两个历史结果各自保留，详见[原评估记录](38-agent-evaluation.md)。

新版检索把原 20 题与新增两道校准题、八道新留出题合并为 30 题。检索前预先固定三组配置，共用 BGE Small 中文 v1.5 和 320 字符分块。报告按文档去重计算排名，保留实际片段、行号和分数。校准、原评估集和新留出集分开统计，耗时为每次检索的本地测量。

新版 Agent 固定原 12 场景及三个新留出场景，共 17 次用户提问。脚本化上游控制模型行为，业务工具、会话、检索、SSE 和账本按实际代码运行。每题记录断言、实际工具与来源、首段文本和总时长、实际 usage 及费用预留。首段计时从准备会话轮次开始，到第一次非空 delta，不包括浏览器或 Nginx 网络。来源覆盖只统计正文确实引用了对应预期文档片段的题。

报告生成唯一文件，保存题集与关键源码 SHA-256、资料和模型索引指纹、配置和模式。真实上游模型名是服务端别名，报告无法确定供应商具体权重版本。脚本化替身提供的 Token 只用于核对记账链路。

## 复现入口

默认 CI 使用 `mvn -Pci test`，运行权限、协议、评分器与新版样本结构检查。下列完整入口有独立开关，缺少开关时即使指定类也会跳过。

```powershell
mvn '-Dtest=RuleRetrievalBaselineTest' '-Dagent.evaluation.retrieval=true' test
mvn '-Dtest=AgentEvaluationV3Test' '-Dagent.evaluation.v3=local' test
```

两者都使用已准备的本地 BGE 文件。检索入口可通过 `agent.evaluation.bge-directory` 指定位置。Agent 入口使用 `app.agent.rag.model-directory`。Agent 评测需先在隔离 MySQL 创建空的 `limited_trade_acceptance`，依次应用 `schema.sql` 和 002 至 016，跳过业务种子与演示数据。使用测试数据源指向该库，为应用配置提供隔离的数据库和中间件参数。运行前会核对数据库名和相关表为空。预算台账使用独立事务，整轮后请回收此专用库。

从同样的空隔离库开始，经授权可把第二条命令的 `local` 改成 `live`，通过环境提供密钥。该入口固定 DeepSeek Flash 及 2 元本地估算准入上限，使用全部 15 场景，没有自动重试。供应商账单以服务端数据为准。本轮未运行该入口。

报告位于 `tools/evaluation-baselines/`，默认 CI 不运行真实模型。
