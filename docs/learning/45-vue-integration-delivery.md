## 完整业务路径

### 买家和公开页面

真实UI注册→登录→刷新恢复身份→退出及受保护路由重定向。游客商品分类命中13件，12+1分页；名称过滤命中4件，空结果有提示。UI注册后的账号仍为USER。

真实地址新增、编辑、默认切换、删除与表单校验，同账号焦点确认不丢草稿。活动下单选择本人券：两件199元减10元为189元，成交地址快照不随地址簿修改。

购物车设数量、改数量、移除、选中结算，未保存数量不提交。对真实已创建订单人为丢弃响应，刷新后保留同一requestId及参数；账号隔离、重试CSRF拒绝不丢购买意图；确认请求返回原订单，未重复创建。普通直接购买也通过。购物车套件最终3笔订单按requestId和金额核对。

本人订单10+1分页、六种状态筛选；取消回补库存并释放券，模拟支付消耗券，管理员发货后确认收货。重复操作符合既有幂等约定。支付已成功但丢弃响应后，页面阻止重复POST，GET确认结果。过期支付返回409，后端仍为待支付时可取消；本轮过期/关闭由隔离样本控制，不当作真实TTL关闭证据。查询到匹配订单能确认未知购买，旧checkout结果URL共用订单详情。订单套件最终15笔订单核对通过，他人订单详情和操作为404。

### 管理员与买家闭环

管理员创建/重命名分类、重名409；商品初始下架，PATCH上下架反映公开列表，编辑资料不修改库存；创建活动和券，表单金额和时间越界拦截。

买家领取管理端新券，两件原价59.80减5，应付54.80并模拟支付。管理员按用户/状态分页，列表不包含地址、详情包含成交地址；填写物流并确认登记，买家收货后管理详情为COMPLETED。相同物流重复200，不同物流409，无地址订单不能发货。

对真实发货/创建成功后丢弃响应，页面阻止自动重发，刷新确认真实结果。受控403能显示trace。USER无法进入六条管理路由，真实管理接口403；对本轮样本角色变更并重新登录后，页面清除管理内容与草稿。管理套件最终14笔订单核对通过。

### 开发库真实Agent

使用开发库新建的随机测试用户与订单，不使用既有账号；恢复USER身份后发问。DeepSeek实际调用list_my_orders和search_trade_rules，回答包含本人订单及59.90金额，没有引用另一用户订单，展示3条实际RAG来源。首问401个delta、2次模型调用/2次工具调用、4668ms；追问1次模型调用/0工具、1019ms，正确复述上下文。

数据库核对保存1轮→2轮；页面清空后为0轮。另一账号发送和清空本人的会话均404；本账号清空他人会话也404。刷新只恢复编号，页面不伪造旧消息。正文未放sessionStorage。数据是本轮样本，耗时不是基准或总体准确率。

实际模型请求共3次：首轮回答成功但脚本用外来订单编号2做任意子串判断，误匹配时间中的2；修正为订单编号上下文判断，清理首轮样本后，两次问答完整通过。此问题没有修改后端权限或回答逻辑。
