# 商城人工验收

## 测试环境

- Vue 优先从 [本机 Nginx 入口](http://127.0.0.1:18083/) 打开，启动及停止步骤见 [Nginx 静态入口](learning/47-strengthening-vue-static.md)。Vite 备用入口是 [127.0.0.1:5173](http://127.0.0.1:5173/)。同一次测试使用同一个地址，登录状态依赖各自的浏览器会话。
- 使用日常开发库的默认扩展商城。首次安装按 [数据库初始化](../README.md#数据库初始化首次准备) 导入数据。本机已有数据继续使用，无需重新初始化。
- 买家可使用已有 USER 账号或自行注册。管理员使用已有 ADMIN 账号，建议为两种角色各开一个独立浏览器会话。购买、发货、领券及管理操作会写入开发库，请用专门的测试订单和地址。
- Java 显式启用 Agent 和 RAG 后再测试助手。手动发送问题会访问配置的模型服务。 [启动说明](../frontend/RUNNING.md)

## 按顺序检查

| 流程 | 操作 | 预期 |
| --- | --- | --- |
| 注册与登录 | 新注册一个买家账号并登录。用另一浏览器会话登录已有管理员账号 | 注册后跳到登录页，买家登录后进入商品浏览，管理员进入管理中心 |
| 商城 | 游客浏览商品，用“扩展演示”搜索，切换分类及分页 | 能筛选、翻页，点击商品卡进入详情 |
| 活动与券 | 核对活动年份及状态，再进入进行中的活动领取一张券 | 已结束活动关闭参加入口，进行中的活动展示价格、门槛和截止时间 |
| 下单 | 买家保存地址，检查成功弹窗，再从商品详情加入购物车并结算，另做一笔活动券单 | 显示成交金额、券优惠、商品清单和地址快照 |
| 履约与撤销 | 买家模拟支付，管理员登记物流，买家确认收货。另建一笔待支付订单后取消 | 订单依次进入已支付、已发货、已完成。取消后库存、活动名额及券按原规则回补 |
| 交易助手 | 从订单详情点「问这笔订单」，发送预填问题，再问支付截止规则 | 回答使用本人订单事实，规则回答可展开原文。刷新仍能读到已保存轮次 |
| 断流与权限 | 生成中点「停止生成」。退出后尝试打开本人订单、助手或管理链接 | 页面自动给出该轮保存结果。受保护页面需要登录，普通账号无法访问管理页 |

模拟支付不产生真实扣款。物流登记保存填写的承运方和运单号。

## 响应丢失的验证范围

隔离浏览器验收会让下单、支付、发货和收货在数据库提交成功后丢失 HTTP 回执，再检查页面自动恢复、订单去重和库存一致。前端测试另覆盖助手 SSE 丢失最终事件后读取到本轮已保存回答且只请求一次生成。普通断网无法稳定复现「已提交但回执丢失」的时机。 [配套验收入口](learning/46-strengthening-acceptance-ci.md)

本地确定性 CI 使用 Java 21 与 Node 24，默认不调用真实模型。远端版本和工作流见 [GitHub 仓库](https://github.com/Elaina168/limited-trade-platform) 和 [GitHub Actions](https://github.com/Elaina168/limited-trade-platform/actions)。
