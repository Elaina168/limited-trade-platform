# 补强 2 · Vue 静态托管与统一入口

**目标**：Nginx 直接托管 Vue 构建产物，浏览器通过同一来源访问 Java API。

**设计**：增加独立 Nginx 配置，默认监听回环 18083，代理到 8080。复用现有网关的请求追踪与日志格式。HTML 每次重新验证，带构建哈希的资源长期缓存，API 强制 no-store。API 保留原始响应，SSE 关闭缓冲，客户端中止时关闭上游连接。

**范围**：[补强路线](2026-11-23-project-strengthening.md#补强2vue正式静态托管与统一入口)。保留 Java 原生入口及 Vite 调试模式。沿用本机 Nginx、JDK、Node、MySQL 和浏览器；真实模型调用、HTTPS 和容器编排分别留到对应验收。

## 实施与验收

1. 增加 `deploy/nginx-vue` 配置，给既有启停脚本增加 `vue` 模式。运行 `nginx -t`，核对该模式的进程和健康路由。
2. 在补强 1 的隔离浏览器入口新增可选 Nginx 模式。复用临时 MySQL 和交易流程，使用独立监听端口和临时前缀，直接服务 dist。检查 SPA 深链接、缺失静态资源、API 错误、缓存头和 Java 原生首页。
3. 让真实 Java Agent 连接本地可控模型替身。第一轮收到首段后才释放尾帧，核对完成与保存。第二轮从 Vue 停止，核对上游连接关闭、生成资格释放且只保留成功轮。
4. 核对 Vite preview 路径，回收临时进程。记录运行命令、证据及源码学习顺序。
