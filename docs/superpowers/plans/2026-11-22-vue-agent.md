# Vue第六阶段：Agent聊天与SSE

按已授权的七阶段计划，将现有Java Agent会话/SSE接入Vue；不增加依赖，不改后端模型协议，不自动提交推送。

## 已核对契约与边界

POST /api/agent/conversations返回conversationId/expiresAt；DELETE /{id}/messages为204；POST /{id}/messages/stream携带JSON message，1至2000字符，Session/CSRF。事件start、delta(round/text)、reset(round/text)、done(AgentChatResponse)、error(code/message)。done发送前服务端已保存成功历史，只有它确认完成。

当前没有GET历史或会话列表。只按用户把会话编号放sessionStorage，正文/来源仅内存最近六轮，刷新后说明未重载旧消息。新会话成功才替换，清空确认后DELETE成功才移除本地消息；失败或停止不假装保存/清空成功，不自动重发。页面离开和身份变化停止旧请求，防止迟到事件污染新身份。来源仅取done实际返回内容，正文纯文本展示。

config/agent.properties已有DeepSeek密钥且enabled=false，模型deepseek-flash；本轮仅通过运行参数开启临时验证实例，密钥不进入浏览器/日志。模型与RAG本地文件已存在。information_schema确认测试库两张会话表齐全，开发库未有014两表；本轮用测试库，开发库迁移留运行环境收尾核对。
