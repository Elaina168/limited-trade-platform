# 收货地址与订单地址快照

## 个人地址与首次默认
登录后可管理本人地址。第一次新增地址会设为默认地址，后续可手动更换默认地址。设置新的默认地址会清除旧默认，默认只能有一个。

## 删除默认地址
删除地址只删除本人地址簿中的那条记录。删除默认地址后，系统不会自动把其他地址设为默认；可以自行选择并重新设置。

## 下单与地址选择
购物车结算必须提供本人地址。直接下单接口允许省略地址。提供地址时必须属于登录用户，地址不存在或不属于本人时无法使用。

## 历史订单地址
创建订单时保存所选地址的独立快照。下单后改动或删除地址簿地址，不会改动历史订单的地址快照。管理员登记发货时需要订单已有地址快照。
