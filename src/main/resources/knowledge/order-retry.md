# 下单重试、幂等标识与限流

## 相同请求重试
直接下单和购物车结算都使用请求标识 requestId。相同账号以原请求标识重试同一笔购买，会返回首次生成的同一订单，不会再创建订单或扣库存。

## 参数发生变化
同一个请求标识不能用于不同购买。直接下单重试若改动商品、数量、活动、优惠券或地址，会返回 409。将一次直接下单的标识用于购物车结算，也会返回 409。

## 购物车已清空之后重试
购物车购买成功后，选中的商品会从购物车删除。用原标识、相同商品集合和相同地址重试，仍能返回第一次的成交结果。重新加入商品不会改变第一次成交时保存的数量和金额。

## 请求过于频繁
直接下单和购物车结算共用按登录账号计量的限流额度。限流检查在订单幂等检查之前；请求过多会得到 429 和建议等待秒数 Retry-After，等候后仍可用原标识重试。
